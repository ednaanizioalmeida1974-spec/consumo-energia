# ⚡ Calculadora de Consumo de Energia

## 📌 Sobre o projeto

Este projeto calcula o consumo mensal estimado de um aparelho elétrico.

O usuário informa o nome do aparelho, sua potência em watts e quantas horas por dia ele é utilizado.

## 💻 Tecnologias

- Python 🐍
- GitHub 🐙

## 🧮 Fórmula

consumoMensal = (potencia × horasDia × 30) / 1000

O resultado é apresentado em kWh/mês.

## ▶️ Como executar

1. Ter o Python instalado.
2. Abrir o terminal na pasta do projeto.
3. Executar:

python app.py

4. Informar os dados solicitados pelo programa.

## 📊 Exemplo

Aparelho: Geladeira

Potência: 150 W

Uso diário: 10 horas

Consumo estimado: 45 kW/mes
